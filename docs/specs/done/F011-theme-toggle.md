# F011 - Theme Toggle

## Problem
Users want a light/dark theme option stored across sessions.

## Goal
Provide a theme toggle persisted in local storage, with a CSS variable based system.

## Acceptance Criteria
- Toggle in profile or settings
- Persists between sessions
- Uses Tailwind v4 variables
